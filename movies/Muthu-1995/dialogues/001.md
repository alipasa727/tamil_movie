有名な決め台詞は、いつ、どのように自分が現れるかは誰にも分からないが、必要な時には現れる、という趣旨です。今回はその中の短い否定表現を学びます。場面と前後関係は、視聴時に確認して追記します。

同じ決め台詞の前半は [002](002.md)、結びは [003](003.md) を参照してください。

## 1. タミル語の原文

> யாருக்கும் தெரியாது.

## 2. 日本語訳

**自然な訳：** 誰にも分からない。

**直訳：** 誰にとっても、知られていない。

**ニュアンス：** この部分だけでは「何が分からないか」は明示されていません。前後の文脈を受けています。「誰も知らない」とも訳せます。

## 3. 文法解説

**文法の照合状況：** 文法資料によるノート単位の照合は未実施。原文の掲載資料を確認した状況とは別に扱います。

### 単語と形の分解

| 要素 | 意味・働き |
| --- | --- |
| யார் | 「誰」。人を尋ねる疑問語 |
| -உக்கு | 与格の接辞。「〜に」 |
| -உம் | 「〜も」。疑問語と組み合わさり、否定文では「誰にも〜ない」という意味を作る |
| தெரி | 「分かる／知られる」に関わる語幹 |
| -ஆது | この動詞の否定形を作る部分。語幹との間に音のつなぎが入る |

### 文の組み立て

「誰」＋与格「〜に」＋「〜も」と、後ろの否定形が組み合わさり、「誰にも分からない」になります。

タミル語では「分かる・知っている」を表すとき、知っている人を与格の「〜に」で示す構文がよく使われます。日本語の「私は知っている」に、そのまま主格の「私は」を対応させるとは限りません。

### 文法のポイント

1. 疑問語が含まれていても、必ず疑問文になるわけではありません。「〜も」の接辞と否定の述語を合わせて読みます。
2. この否定形は「分からない／知らない」という状態を表します。この形だけから「知らなかった」という過去の意味に決めないようにします。
3. 文脈で分かる「何を」が省略されています。訳で補う場合は、原文に書かれている内容と区別します。

## 4. 練習と復習

**確認問題：** 「誰」を表す語があるのに、なぜ質問にならないのでしょうか。

**答えと理由：** 「〜も」の接辞と否定の述語が組み合わさっているためです。語1つだけでなく、文全体から「誰にも〜ない」と解釈します。
