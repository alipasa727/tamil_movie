# 映画の台詞と歌詞で学ぶタミル語

映画ごとにフォルダを作り、台詞と歌詞を **タミル語の原文・日本語訳・文法解説** のセットで整理する学習ノートです。タミル文字が読める前提で、文法と表現の理解を中心に進めます。

最初の作品は、ラジニカーント主演の [『Muthu／ムトゥ 踊るマハラジャ』](movies/Muthu-1995/movie.md) です。

## Muthuの学習ノート

| 種別 | ノート | 学ぶ内容 |
| --- | --- | --- |
| 台詞 | [001：誰にも分からない](movies/Muthu-1995/dialogues/001.md) | 与格と否定 |
| 台詞 | [002：俺がいつ来るか](movies/Muthu-1995/dialogues/002.md) | 口語の疑問語、未来、一人称単数 |
| 台詞 | [003：きっちり現れる](movies/Muthu-1995/dialogues/003.md) | 英語由来の副詞、約束の表現 |
| 歌詞 | [001：Oruvan Oruvan Mudhalali](movies/Muthu-1995/songs/001.md) | 名詞の述語と反復 |
| 歌詞 | [002：Thillana Thillana](movies/Muthu-1995/songs/002.md) | 連体形、疑問形、恋の比喩 |
| 歌詞 | [003：Kokku Saiva Kokku](movies/Muthu-1995/songs/003.md) | 名詞の修飾とつなぎの子音 |

各ノートに原文の出典リンクを記録しています。台詞の3件は同じ決め台詞の短い部分を分けたものです。掲載資料で表記を確認済みですが、映画本編や公式音源との照合、場面・タイムスタンプの確認は未実施です。日本語訳と解説は学習用に作成しています。

## フォルダ構成

```text
movies/
  _template/                  # 新しい映画用のひな形
    movie.md                 # 映画の基本情報と学習の進み具合
    dialogues/
      001.md                 # 台詞1つ分の学習ノート
    songs/
      001.md                 # 歌詞の短いまとまり1つ分の学習ノート
  映画タイトル-公開年/       # 映画ごとにひな形をコピーして作成
    movie.md
    dialogues/
      001.md
      002.md
    songs/
      001.md
```

## 新しい映画を追加する

`movies/_template` をコピーして、映画タイトルと公開年をフォルダ名にします。映画名が未定の間は、ひな形のままで使えます。

```bash
cd /workspace/tamil_movie
cp -R movies/_template 'movies/映画タイトル-公開年'
```

`movie.md` に作品情報を記入し、`dialogues/001.md` に最初の台詞、`songs/001.md` に最初の歌詞をまとめます。資料が増えたら、それぞれ `002.md`、`003.md` とファイルを追加します。原文は、手元の字幕や歌詞、聞き取った内容をもとに記録します。

## 台詞1つの学習手順

1. 場面と話者、タイムスタンプ、原文の出典を記録する。
2. タミル語の原文を記入する。聞き取れない部分は推測で埋めず、未確認と記す。
3. 自然な日本語訳と、語順や文法がわかる直訳を分ける。
4. 単語・語幹・接辞に分解し、文法と口語表現を確認する。
5. 音声を聞いて発音を練習し、日本語訳から原文を思い出して復習する。

カタカナの読みは補助として使い、タミル文字と音声も一緒に確認します。口語と書き言葉が異なる場合は、それぞれを区別して記録します。

歌詞では、短いまとまりごとに区切り、文法に加えて比喩・詩的な語順・省略も確認します。繰り返し部分は、同じ解説を重複させず参照で整理できます。

## 開発環境

Markdown の編集だけなら、追加パッケージ・API キー・起動サーバーは不要です。現在のクラウド環境では Python 3 と Pandoc が利用できます。HTML に変換して内容を確認する場合は、リポジトリの外へ出力します。

```bash
cd /workspace/tamil_movie
pandoc --standalone --metadata title='タミル語の学習ノート' \
  movies/_template/dialogues/001.md -o /tmp/tamil-dialogue.html
```

このリポジトリにはアプリケーションや自動テストはまだありません。学習ノートの編集、タミル文字の保存、Markdown の HTML 変換を環境の確認対象とします。
